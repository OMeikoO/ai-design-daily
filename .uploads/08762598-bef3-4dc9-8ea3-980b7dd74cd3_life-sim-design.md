# 《浮生》——0-75岁中国人生模拟文字游戏 设计方案

> 文档定位：交付给工程团队的开发设计文档。覆盖玩法机制、内容结构、数据模型、技术要点，工程师可据此直接进入实现。
> 版本：v1.0  ｜ 适用范围：Demo 版（MVP）

---

## 1. 项目定位与设计目标

### 1.1 一句话定义

一款以**周为节奏单位**、用克制旁白与稀疏选择还原普通人一生的文字模拟游戏，时间跨度 0-75 岁，背景扎根中国近现代，强调"放空、想象、回望"的叙事体验。

### 1.2 与已有产品的差异化

| 维度 | 人生重开模拟器 | BitLife | 本作《浮生》 |
|------|---------------|---------|--------------|
| 推进单位 | 1 年/步 | 1 年/步 | **1 周/步（剧情节点）** |
| 决策密度 | 开局后几乎无决策 | 每年多卡轰炸 | **按年龄曲线调节，平均一周一选** |
| 单次影响 | 终身累积 | 数年内 | **≤3 个月** |
| 叙事风格 | 网络梗密集 | 紧凑事件流 | **克制旁白+留白** |
| 背景 | 抽象中式 | 美式 | **中国近现代真实时代细节** |
| 结局 | 数值评级 | 数值评级 | **数值线 + 叙事线并行** |

核心差异：把 lifeRestart 的"年推进"细化为"周推进"，把 BitLife 的"事件轰炸"改为"呼吸式节奏"，用 A Dark Room 的留白手法处理婴幼与暮年段落。

### 1.3 设计目标（可验证）

- 玩家完成一生所需的**主动决策数控制在 180-260 次**之间，平均每周一次，关键年龄密集、平淡年龄稀疏。
- 单次决策带来的时间快进不超过 12 周（3 个月）。
- 玩家全程阅读文字量约 3-5 万字，单段旁白不超过 60 字，决策卡选项不超过 4 个。
- 一周目通关时长 40-90 分钟，多周目复玩率目标≥40%（靠 meta-progression 与隐藏线）。

### 1.4 目标用户

- 偏好文字、慢节奏、想象空间的玩家；
- 对"如果当年 differently"有好奇心的成年人；
- 在通勤、睡前等碎片场景寻求放空的人群。

## 2. 核心设计理念

### 2.1 三条不可动摇的原则

1. **少即是多**：信息只给"刚好够想象"的部分，剩余让玩家脑补。婴幼期不解释"为什么父母吵架"，只写"夜里听见摔碗声"。
2. **选择有重，时间有重**：每个选择都改台词或属性或关系或远期分支，杜绝伪选择；单次选择最多让时间跳 3 个月，避免"一选老十岁"。
3. **真实优于爽感**：中国近现代的时代质感（粮票、下海、考公热、学区房、彩礼）替代网络梗，耐久且能引发代际共鸣。

### 2.2 "放空引导"的实现路径

参考 A Dark Room 的渐进式系统揭露，但 adapted 到人生叙事：

- **婴幼期（0-6 岁）**：玩家几乎不做选择，只读旁白。让玩家"被生活推着走"，感受童年的无力与好奇。
- **青春期（13-18 岁）**：选择密度骤升，呼吸感从"长呼"切换到"短吸"。
- **中年（31-45 岁）**：选择密度最高，但旁白变冷，写"账单、加班、父母体检报告"。
- **暮年（61-75 岁）**：选择再次稀疏，引入"回望"机制，旁白转为第一人称回忆口吻。

这种密度曲线本身就是叙事，比文字更能传达"人生节奏"。

## 3. 时间线系统

### 3.1 年龄段划分

按"中国学制 + 人生阶段 + 时代事件"三轨划分，共 10 段：

| 段号 | 年龄段 | 阶段名 | 核心主题 | 决策密度 |
|------|--------|--------|---------|---------|
| S1 | 0-3 | 婴幼 | 被动感知世界 | 极低 |
| S2 | 4-6 | 学龄前 | 家庭氛围定型 | 低 |
| S3 | 7-12 | 小学 | 同伴世界打开 | 中低 |
| S4 | 13-15 | 初中 | 自我意识觉醒 | 中 |
| S5 | 16-18 | 高中 | 高考分水岭 | 高 |
| S6 | 19-22 | 大学 | 独立与方向 | 高 |
| S7 | 23-30 | 立业 | 城市/职业/初恋 | 高 |
| S8 | 31-45 | 成家立业 | 房贷/婚育/父母老 | 极高 |
| S9 | 46-60 | 收尾 | 中年危机/健康预警 | 中 |
| S10 | 61-75 | 暮年 | 回望与和解 | 低 |

### 3.2 推进单位与"剧情节点"机制

不采用"严格每周一推"，而采用**剧情节点（StoryNode）**驱动：

- 一个 StoryNode = 一段旁白 + 0~4 个选项 + 时间快进量。
- 节点之间的**剧情时间间隔**默认约 1 周，但按年龄调节：
  - 婴幼期：节点间隔可拉到 2-4 周（甚至月），制造"长大得很慢"的感觉。
  - 青春/中年：节点间隔约 1 周，密集时连续多日。
  - 暮年期：节点间隔拉到 2-4 周，时间感变慢。
- 单个节点的时间快进 `timeAdvanceWeeks` 字段取值 0-12，**硬上限 12 周**（即 3 个月），由系统校验拦截。
- 玩家不做选择的节点（纯旁白节点）也算推进，这种节点在婴幼/暮年占比≥60%。

### 3.3 决策密度曲线

整个一生目标决策节点 180-260 个，分布如下（粗略）：

```
决策密度（每周平均选择数）
高 │            ████          ████████
   │           ██  ██        ██      ██
中 │      ████      ██      ██        ████
   │     ██            ████              ██
低 │  ████                                ██
   │██                                      ████

   0  3  6  12  15  18  22  30  45  60  75  年龄
```

这是叙事节奏的"心电图"：童年舒缓、青春期陡升、中年高原、暮年回落。

### 3.4 时代背景系统

出生年份决定时代事件池，让"70 后/80 后/90 后/00 后"各有真实感：

- 出生年份随机或玩家选择（1970-2010 范围内）。
- 时代事件按真实历史挂载，例如：
  - 1970s 出生：粮票末期、恢复高考、下海潮、单位分房。
  - 1980s 出生：独生子女证、小霸王、千禧年、加入 WTO。
  - 1990s 出生：网吧、非典、汶川、QQ 农场、房价起飞。
  - 2000s 出生：智能手机、双减、口罩三年、AI 元年。
- 时代事件作为"背景音"穿插旁白，不一定给选择，但提供年代锚点。

## 4. 属性系统

### 4.1 五维属性

| 属性 | code 字段 | 含义 | 影响范围 |
|------|----------|------|---------|
| 颜值 | `charm` | 外貌吸引力 | 恋爱成功率、部分职业（销售/演艺）、社交评价 |
| 智力 | `intel` | 学习与认知 | 升学阈值、收入上限、信息判断 |
| 体质 | `health` | 身体素质 | 寿命、疾病抗性、老年生活质量 |
| 家境 | `family` | 出身资源 | 起点资源、能否上重点、早期事件走向 |
| 心境 | `mood` | 情绪状态（隐藏显示） | 负面事件概率、关系维护、结局叙事 |

- 五维均采用 1-10 整数制（开局分配 + 后天增减）。
- 心境默认对玩家**半隐藏**：界面只显示"晴/阴"图标，不显示具体数值，制造"说不清的情绪"感。仅在低至阈值时弹出"最近总提不起劲"类旁白。
- 属性**阈值触发**而非线性加成：例如 `intel≥7` 才能上 211 大学，`charm≥6` 才会被表白，制造"差一点差很多"的戏剧性。

### 4.2 开局分配

- 五维共 20 点自由分配，每项 1-10。
- 分配后抽 3 个天赋（10 选 3），天赋可加成或惩罚。
- 出身家境随机区间：1-10，但允许玩家用 2 点分配额度"锁定"家境（呼应"投胎是技术活"）。

### 4.3 天赋示例

| 天赋 | 效果 | 类型 |
|------|------|------|
| 早慧 | 智力+2，但心境上限-1 | 双刃 |
| 邻家小孩 | 颜值+1，家境+1 | 正向 |
| 体弱多病 | 体质-2，但疾病事件获得额外旁白 | 负向 |
| 城中村 | 家境-2，但 18 岁后家境每 5 年+1（逆袭线） | 双刃 |
| 早产儿 | 体质上限锁 7，但触发"奇迹康复"隐藏线条件 | 负向 |
| 书香门第 | 智力+1，家境+1，但 18 岁必触发"是否继承家业"分支 | 双刃 |

## 5. 事件与选择系统

### 5.1 事件池结构

事件池为 JSON 数组，单条事件结构：

```json
{
  "id": "evt_gaoKao_001",
  "stage": "S5",
  "ageRange": [18, 18],
  "requirement": { "intel": ">=5", "mood": ">=4" },
  "excludeIf": { "tags": ["dropout"] },
  "weight": 100,
  "narration": "六月的蝉叫得人心烦。准考证攥出汗，监考老师走过你身边停了一下。",
  "choices": [
    {
      "text": "认真答完每一题",
      "effects": { "intel": "+0", "mood": "-1", "stress": "+2" },
      "timeAdvanceWeeks": 2,
      "nextNode": "node_gaoKao_result",
      "setFlags": ["gaokao_normal"]
    },
    {
      "text": "最后一道大题赌一把，写满",
      "requirement": { "intel": ">=6" },
      "effects": { "mood": "-2", "stress": "+3" },
      "timeAdvanceWeeks": 2,
      "nextNode": "node_gaoKao_result_gamble",
      "setFlags": ["gaokao_gamble"]
    },
    {
      "text": "交白卷，回家",
      "effects": { "mood": "+2", "family": "-1" },
      "timeAdvanceWeeks": 2,
      "nextNode": "node_dropout",
      "setFlags": ["dropout"]
    }
  ]
}
```

### 5.2 触发引擎逻辑

事件触发按优先级链：

1. **主分支节点**（强制触发，如高考、30 岁抉择、45 岁危机）。
2. **属性阈值事件**（满足条件且未触发过，按 weight 抽 1）。
3. **年龄段事件**（在该段年龄区间内随机）。
4. **时代背景事件**（出生年份+当前年龄命中历史节点）。
5. **关系网事件**（父母/伴侣/子女触发的支线）。
6. **纯旁白节点**（兜底，保证节点不空）。

每推进一个节点，引擎按上述顺序判断，命中即停。

### 5.3 蝴蝶效应：3 个主分支点

参考 Life is Strange 的远期后果机制，设 3 个"主分支点"，每个主分支的远端后果延迟 5-15 年显现：

| 主分支点 | 触发年龄 | 选项示例 | 远端后果（5-15 年后） |
|---------|---------|---------|---------------------|
| 高考 | 18 | 985/211/普通本科/复读/弃学 | 28 岁职业天花板、35 岁裁员风险、是否进体制 |
| 三十而立 | 30 | 留大城市/回老家/出国/创业 | 40 岁房贷压力、45 岁子女教育路径、父母养老 |
| 中年抉择 | 45 | 跳槽创业/守成/提前退休/照顾父母 | 60 岁财务状态、健康状况、与子女关系 |

主分支点的选择会设置 `flags`，远端事件读取 flags 触发不同分支。例如 18 岁选"复读"→ 19 岁再高考 → 若考上 985 则 28 岁触发"同龄人都工作了"心境事件；若再落榜 → 20 岁触发"南下打工"支线。

### 5.4 隐藏线（梯度触发，避免 lifeRestart 的"触不到"问题）

lifeRestart 修仙线条件过苛，多数玩家触不到。本作采用**梯度触发**：

- 弱条件 → 浅线（多见）：例如体质≥5 + 心境≥5 → 50 岁触发"晨跑"支线，体面养老。
- 中条件 → 中线（少见）：智力≥7 + 18 岁选 985 + 30 岁选留大城市 → 40 岁触发"创业"线。
- 强条件 → 深线（罕见）：家境≥8 + 颜值≥7 + 智力≥6 + 持有"书香门第"天赋 → 25 岁触发"继承家业"主线，35 岁决裂/中兴二选一。

每个隐藏线都有**浅入口**，玩家哪怕没走深也能体验到一部分，避免"一辈子啥都没发生"的挫败。

## 6. 年龄段详细设计

每段给出主题、节奏、典型事件、旁白示例。

### S1 婴幼期 0-3 岁

- **节奏**：节点间隔 2-4 周，决策节点占比<15%。
- **主题**：被动感知，建立对父母/家境的初始印象。
- **典型事件**：夜哭、断奶、第一次走路、父母是否吵架、是否上托班。
- **旁白风格**：感官化、无判断。"墙上的钟滴答，妈妈抱着你来回走。"
- **玩家选择示例**：基本无选择，偶尔给"哭/不哭"这种几乎无后果但定调心境的"装饰性选择"。

### S2 学龄前 4-6 岁

- **节奏**：节点间隔 1-2 周，决策占比 20%。
- **主题**：家庭氛围定型，"原生家庭"基调在此埋下。
- **典型事件**：是否上幼儿园、父母下岗/调动、邻居小孩、第一次撒谎。
- **旁白示例**："爸爸的厂子黄了。他开始整天坐在阳台抽烟，烟头攒了一罐子。"

### S3 小学 7-12 岁

- **节奏**：节点间隔 1 周，决策占比 35%。
- **主题**：同伴世界打开，学业压力初现。
- **典型事件**：选兴趣班、被孤立/受欢迎、小升初择校、网吧初体验（90 后）。
- **时代挂钩**：80 后此段遇"减负"口号；00 后遇"双减"。

### S4 初中 13-15 岁

- **节奏**：节点间隔约 1 周，决策占比 50%。
- **主题**：自我意识觉醒、初恋萌芽、叛逆。
- **典型事件**：早恋、沉迷游戏/小说、与父母冲突、文理分科（已取消则改为选科）。
- **旁白示例**："她在你前排，马尾一甩一甩。整节课你都在数她甩了几次。"

### S5 高中 16-18 岁

- **节奏**：决策占比 70%，进入第一个高峰。
- **主题**：高考分水岭。
- **关键节点**：选文理/选科、是否艺考/竞赛、高考本身（主分支点）、志愿填报。
- **特殊**：18 岁高考节点是**强制主分支**，无论属性都会触发，但选项受属性 gate。

### S6 大学 19-22 岁

- **节奏**：决策占比 65%。
- **主题**：独立、方向、第一段认真关系。
- **典型事件**：选专业、社团、入党、考研/保研/就业、初恋分手。
- **时代挂钩**：00 后此段遇"口罩三年"，宿舍封控旁白应有。

### S7 立业 23-30 岁

- **节奏**：决策占比 60%，但旁白转冷。
- **主题**：城市选择、职业定型、初恋→婚姻。
- **关键节点**：第一份工作、北漂/沪漂/回老家、30 岁主分支点。
- **旁白示例**："房租涨了三百。你在地铁里算了一遍又一遍。"

### S8 成家立业 31-45 岁

- **节奏**：决策占比最高（75%），但旁白最克制最冷。
- **主题**：房贷、婚育、父母老去、35 岁危机。
- **关键节点**：买房、结婚、生子、父母重病、35 岁裁员风险。
- **特殊**：此段引入"双线压力"——职场与家庭事件交叉触发，模拟真实中年夹击。

### S9 收尾 46-60 岁

- **节奏**：决策占比 40%，开始回落。
- **主题**：中年危机、健康预警、子女离家、父母离世。
- **关键节点**：体检报告、子女高考（呼应 S5，但视角反转）、父母去世、退休规划。

### S10 暮年 61-75 岁

- **节奏**：节点间隔拉到 2-4 周，决策占比 25%。
- **主题**：回望、和解、衰老。
- **特殊机制——回望**：此段旁白转为第一人称回忆口吻，并会**回引早年的选择**："你还记得十八岁那年填志愿的那个下午吗。窗外知了叫得厉害。"系统读取 `flags`，根据当年选择给不同回望文案。
- **结局判定**：75 岁触发结局，也可因健康/意外提前结束。

## 7. 旁白与文案规范

### 7.1 风格基调

- 克制、白描、感官化，少形容词、少抒情、少判断。
- 第一人称内视角（童年可切第三人称"你"），不剧透未来。
- 自嘲允许但不依赖梗；时代细节替代网络梗。

### 7.2 长度与节奏

- 单段旁白 20-60 字，超 60 字必须拆。
- 连续 3 段旁白后必须给一个选择或一个空行留白（视觉呼吸）。
- 决策卡选项文字≤12 字，避免长选项。

### 7.3 文案示例对比

| 场景 | 不推荐（梗化/抒情） | 推荐（克制白描） |
|------|-------------------|----------------|
| 父母吵架 | "原生家庭 PTSD 严重了家人们谁懂啊" | "夜里听见摔碗声。你把被子拉过头顶。" |
| 高考 | "命运齿轮开始转动！冲冲冲！" | "六月蝉叫得人心烦。准考证攥出汗。" |
| 失业 | "35岁被优化，狠狠共情了" | "HR 找你谈话时，你正在改一份 PPT。她说了三句，你只听清'交接'。" |
| 老年 | "夕阳红，老当益壮！" | "电视开着，你没看。窗台上的君子兰开了第三茬。" |

### 7.4 时代细节库（示例，code 可扩展为 JSON）

```
1978 听见广播里说恢复高考
```

## 8. 结局系统

### 8.1 双线结局

**数值线**：按五维数值与寿命给出评级（参考 lifeRestart 但更克制）：
- 评级维度：享年、五维峰值、关系完整度、心境均值。
- 评级词避免"逆天/仙王"式爽感，改用"安稳/体面/潦草/未尽"等中性词。

**叙事线**：根据一生关键 flags 组合，给出一段 200-400 字的"一生回望"散文式结局，引用玩家做过的具体选择。例如："你十八岁那年赌了一把，把最后一道大题写满了。后来你常想起那个下午。"

两条线**并列展示**，数值线在下、叙事线在上，叙事线为主、数值线为辅，避免"刷数值"疲劳。

### 8.2 结局多样性

- 至少 12 种叙事结局模板（安稳一生、潦草收场、未尽之愿、涅槃重来、温暖平凡、孤独终老……）。
- 数值线评级 6 档，与叙事线组合产生≥30 种最终呈现。

## 9. 多周目 meta-progression

参考 Progress Knight，重开可保留部分成长，提升复玩率且契合"人生重开"主题：

- 通关后解锁"人生感悟"点数，可点亮 meta 天赋（不影响当周目，影响后续周目）：
  - 「早记事」：婴幼期旁白+20%，更早进入有选择阶段。
  - 「老来福」：暮年心境衰减-30%。
  - 「续命术」：体质上限+1。
  - 「通透」：可看见选项的隐藏后果提示（二周目以上解锁）。
- meta 天赋最多点亮 5 个，避免数值膨胀。

## 11. 技术实现要点

### 11.1 推荐技术栈（建议，非强制）

- 纯前端单页应用即可承载 Demo：React/Vue + 本地 IndexedDB 存档。
- 事件池为静态 JSON，可全量加载（Demo 量级 300-500 事件足够）。
- 后续若要云端存档/分享结局，再加轻量后端（Node + SQLite）。

### 11.2 核心模块

```
┌─────────────────────────────────────────────┐
│  UI 层：旁白展示 + 选项卡 + 属性条 + 时间轴    │
└─────────────────────────────────────────────┘
                    ↑↓
┌─────────────────────────────────────────────┐
│  游戏循环 GameLoop                           │
│  - 推进一个节点 → 渲染 → 等待玩家选择          │
└─────────────────────────────────────────────┘
                    ↑↓
┌──────────────┬───────────────┬──────────────┐
│ 事件引擎      │ 状态机/Flags  │ 存档管理      │
│ EventEngine  │ FlagMachine   │ SaveManager  │
└──────────────┴───────────────┴──────────────┘
                    ↑↓
┌─────────────────────────────────────────────┐
│  数据层：events.json / talents.json / era.json│
└─────────────────────────────────────────────┘
```

### 11.3 事件引擎伪代码

```
function nextNode(state):
  # 1. 主分支强制触发
  if 主分支点命中(state.ageWeeks, state.flags):
    return 主分支节点
  # 2. 属性阈值事件
  candidates = events.filter(e =>
    inAgeRange(e, state.ageWeeks) &&
    meetRequirement(e, state.attrs) &&
    notExcluded(e, state.flags) &&
    notTriggered(e, state.history)
  )
  if candidates: return weightedPick(candidates)
  # 3. 时代事件
  eraEvt = matchEraEvent(state.birthYear, state.ageWeeks)
  if eraEvt: return eraEvt
  # 4. 关系事件
  relEvt = matchRelationEvent(state.relationships)
  if relEvt: return relEvt
  # 5. 兜底旁白
  return pickAmbientNarration(state.currentStage)
```

### 11.4 存档与回看

- 每个节点推进后自动存档到 IndexedDB（防误关）。
- 完整 `history` 保留，暮年"回望"机制读取 history 生成回引文案。
- 提供"一生时间轴"视图：通关后可回看自己做过的所有选择，强化"如果当初"的代际共鸣。

### 11.5 性能与边界

- 单周目 history 不超过 500 条，内存占用可控。
- 事件池全量<1MB，首屏加载无压力。
- 时间快进字段 `timeAdvanceWeeks` 在引擎入口做 ≤12 校验，超限报错（防御性编程）。

## 13. 风险与边界

| 风险 | 应对 |
|------|------|
| 周推进导致节点过多、文案工作量爆炸 | 用节点模板+变量插值降低重复文案撰写成本；婴幼/暮年纯旁白节点可复用模板 |
| 玩家觉得"无聊"（放空过度） | 决策密度曲线兜底；婴幼段控制在<15 分钟，快速过渡到有选择的学龄段 |
| 时代事件写错年代 | 时代事件库按"年份+年龄"双校验，code 侧加断言 |
| 单次选择被误设超过 3 个月 | 引擎入口硬校验 `timeAdvanceWeeks ≤ 12` |
| 隐藏线又触不到 | 梯度触发，每条线必有浅入口 |
| 文案过于悲观劝退 | 平凡温暖结局占比≥30%；并非所有一生都是悲剧 |
| 涉及真实历史事件的政治敏感 | 时代事件只做白描背景音，不给评判性选项；口罩等近期事件只写日常感受 |
